# Gato a Casa

Juego HTML de un solo archivo. Para jugar en Mac, abre `index.html` con Safari, Chrome o Firefox.

## Publicar en GitHub Pages

1. Sube todos los archivos de esta carpeta a la rama `main` de un repositorio de GitHub. Incluye la carpeta oculta `.github/workflows/`.
2. En GitHub, abre **Settings → Pages** y elige **GitHub Actions** como fuente.
3. En **Actions**, espera a que termine en verde el flujo **Deploy Gato a Casa to GitHub Pages**.
4. La URL será `https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/`.

El flujo publica el `index.html` de la raíz. No necesita Node.js ni un paso de compilación.

## Publicar en itch.io

Puedes usar el ZIP original `gato-a-casa.zip`: crea un proyecto de tipo **HTML** y marca **This file will be played in the browser**.
